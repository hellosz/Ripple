# 桌面客户端三平台冒烟清单（发版前人工执行）

> 自动化部分：CI 的 `desktop-smoke` job 在 Linux（xvfb）验证主进程 + 渲染进程可启动；
> hub 核心行为由 `packages/hub` 单测覆盖（含 Windows junction/copy 降级逻辑）。
> 以下为需要真机人工验证的主流程，每个平台各过一遍。

## 环境准备
- [ ] 从 GitHub Release 安装对应平台安装包（Linux AppImage/deb、macOS dmg、Windows nsis exe）
- [ ] 首次启动无崩溃，窗口 1280×820，橄榄绿主题正常

## 本地模式（未登录）
- [ ] 侧边栏显示"本地模式 · 未登录"；技能市场/更新中心显示 🔒，点击进入登录门控页
- [ ] Agent 列表正确检测本机已装 Agent（绿点）；未装的置灰
- [ ] 设置 → 技能来源：添加 GitHub 仓库（如 anthropics/skills）→ 从来源安装一个技能成功
- [ ] 设置 → ZIP 导入：选择含 SKILL.md 的 ZIP 安装成功
- [ ] Windows 专项：无开发者模式下安装 → 分发方式显示 junction 或 copy（不报错）

## 扫描 → 安装 → 同步 → 回退（主流程）
- [ ] "重新扫描本地目录"toast 汇报结果；手工放入 Agent 目录的技能被识别为 unmanaged
- [ ] 登录后从技能市场安装技能 → 弹同步弹窗 → 勾选多个目标 → 应用成功，本地列表出现安装矩阵 chips
- [ ] 对同一技能"同步…"取消一个目标 → 该目标目录中的分发被移除
- [ ] 展开技能行：禁用开关 → Agent 目录条目消失；启用 → 恢复
- [ ] "历史" → 回退到旧版本 → SKILL.md 版本号变化、时间线新增回退记录
- [ ] 设置 → 备份管理：恢复/删除备份行为正确
- [ ] 卸载技能 → 自动产生"卸载前自动备份"

## 设置迁移
- [ ] 中心存储 内置 ↔ 共享 切换：技能内容迁移、分发不断链、状态保留
- [ ] 分发方式 symlink ↔ 复制 切换：目标目录形态相应变化

## Deep Link 与更新
- [ ] 浏览器打开 `ripple://install?skill=<slug>`：唤起/聚焦应用并进入安装流程（macOS open-url、Win/Linux 第二实例）
- [ ] 存在更高版本 Release 时：应用后台下载并出现"重启更新"横幅，点击后完成升级

## 登录/登出
- [ ] 配置服务地址 + 邮箱密码登录成功；重启应用登录态保持（token 安全存储）
- [ ] 退出登录 → 回到本地模式，本地管理不受影响
