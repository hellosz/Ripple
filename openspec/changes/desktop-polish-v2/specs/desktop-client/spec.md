# desktop-client（delta）

## ADDED Requirements

### Requirement: 连接卡登录态表达 v2
连接卡 MUST 不再显示"已登录"字样：登录态以头图面板+昵称呈现；未登录时 MUST 仅显示 Logo 与 Ripple 字样且背景置灰。Logo 区 MUST 垂直对齐、消除多余上留白。

#### Scenario: 未登录态
- **WHEN** 用户未登录打开应用
- **THEN** 连接卡为置灰背景，仅 Logo+Ripple，点击进入登录

### Requirement: 项目分组视图与关联清理
「仅项目」筛选 MUST 按项目分组折叠展示全部关联项目的技能；移除项目关联后其技能 MUST 不再显示（作用域安装记录清理，磁盘文件保留）。

#### Scenario: 移除项目关联
- **WHEN** 用户移除 vesta-platform 项目
- **THEN** 「仅项目」视图不再出现其技能，项目目录内文件原样保留

### Requirement: 列表头 Agent 批量操作
本地技能列表顶部 MUST 横排展示各 Agent 图标（悬浮显示名称）；点击 MUST 提供"把当前范围全部技能复制到该 Agent / 从该 Agent 取消复制"两个操作，执行前 MUST 二次确认（显示影响数量）。

#### Scenario: 批量复制确认
- **WHEN** 用户点击列表头 Hermes 图标选择"全部复制"
- **THEN** 确认弹窗显示将影响的技能数量，确认后执行并 toast 结果

### Requirement: 技能行 v3 与本地详情
技能行 MUST：去除技能字母图标、名称+简介为主体、版本以小字显示于「同步」按钮下方、行距更疏松；点击行 MUST 打开本地 Skill 详情——文件树 + 文件内容（等宽字体、行号、VSCode 风格基调），并支持手动编辑与保存（保存写回中心存储并重建复制型分发）。

#### Scenario: 编辑并保存
- **WHEN** 用户在详情中修改 SKILL.md 并保存
- **THEN** SSOT 内容更新、copy 分发重建、操作记录新增「编辑」条目

### Requirement: 市场卡片安装态 v2
市场卡片 MUST 不显示"已安装"文字：已安装以卡片底部 100% 进度条（安装态色）标识；存在待同步更新时进度条与「同步」按钮 MUST 使用区别色。点击卡片 MUST 打开该技能主要信息弹窗（对齐 Web 详情非文件部分），其文件部分风格与本地详情一致。

#### Scenario: 已安装与待同步的视觉区分
- **WHEN** 市场中某技能已安装且无更新、另一技能已安装但远端有新版
- **THEN** 前者底部进度条为安装态色，后者为待同步色且同步按钮变色
