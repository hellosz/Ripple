# desktop-client

## ADDED Requirements

### Requirement: 跨平台支持
桌面客户端 MUST 支持 Linux、macOS、Windows 三平台（Electron + React，与 Web 共享 ui 组件与设计 token），默认窗口 1280×820，视觉遵循原型的橄榄绿主题。本地管理能力 MUST 通过共享 hub 核心库实现（主进程），渲染进程经类型化 IPC 调用。

#### Scenario: 三平台构建产物
- **WHEN** 执行桌面发布构建
- **THEN** 产出 Linux（AppImage+deb）、macOS（dmg）、Windows（nsis exe）安装包且核心功能一致

### Requirement: 侧边栏导航
侧边栏 SHALL 包含：品牌区与连接状态卡（已登录显示昵称与服务地址，未登录显示"本地模式"，点击打开登录/服务设置）、主导航（本地技能/技能市场/更新中心，更新中心带可更新数徽标，未登录时市场与更新中心显示锁标）、Agent 全局列表（检测状态圆点 + 各自安装数，点击进入该 Agent 视图）、项目目录列表（＋添加项目）、"重新扫描本地目录"与"设置"入口。

#### Scenario: 未登录的导航锁定
- **WHEN** 用户处于本地模式点击"技能市场"
- **THEN** 显示登录门控页（说明本地模式可用范围 + "配置服务并登录"按钮），而非市场内容

### Requirement: 本地技能列表
本地技能视图 SHALL 展示当前范围（全部/仅全局/仅项目 chips，或某 Agent/某项目）内的技能行：图标、名称、描述、"可更新"与"版本不一致"徽章、安装矩阵 chips（每处安装的 Agent/项目与启用态，禁用显示删除线）、版本号（多版本并列显示）、历史按钮、"同步…"按钮与展开箭头；支持搜索框过滤与计数显示，空态给出去市场安装的引导。存在版本不一致技能时列表顶部 MUST 显示冲突横幅与"统一到最新版"操作。

#### Scenario: 展开逐处管理
- **WHEN** 用户点击技能行展开
- **THEN** 显示每处安装的作用域标签、目标路径、版本（落后版本高亮）、逐处"更新"、启用/禁用开关与卸载按钮

#### Scenario: 一键解决冲突
- **WHEN** 用户点击冲突横幅的"统一到最新版"
- **THEN** 所有不一致安装统一到最新版本并 toast 确认

### Requirement: 同步弹窗
"同步…"操作 SHALL 打开弹窗：按 AGENT·全局 与 项目·本地目录 两组展示可勾选目标（已安装目标默认勾选），显示目标统一版本、自动备份提示与选中计数；应用后按 local-skill-hub 的同步语义执行并 toast 结果。

#### Scenario: 勾选新目标并应用
- **WHEN** 用户在弹窗勾选一个新 Agent 并点击"应用"
- **THEN** 该 Agent 新增此技能安装，弹窗关闭并提示"已备份并同步到 N 个目标"

### Requirement: 历史弹窗
"历史"操作 SHALL 打开该技能的操作时间线弹窗：每条含动作（安装/同步/更新/回退）、版本、目标描述、时间与"当前"标记；非当前版本行提供"回退到此版本"；底部显示备份目录路径。

#### Scenario: 从历史回退
- **WHEN** 用户点击某历史版本的"回退到此版本"
- **THEN** 执行备份恢复，弹窗时间线顶部出现新的回退记录

### Requirement: 技能市场
登录状态下市场 SHALL 提供三个子视图：浏览（卡片网格：名称/分类/热度/描述/作者/版本/已安装标记，安装或同步按钮）、排行榜（名次/趋势/热度/周传播表格 + 热度公式说明）、合集（策展合辑卡片、逐项已装标记、"装齐整套（N 个未装）"批量安装）。市场安装 MUST 走同步弹窗选择目标。

#### Scenario: 从市场安装新技能
- **WHEN** 用户在浏览网格点击未安装技能的"安装…"
- **THEN** 打开同步弹窗选择目标，应用后该技能出现在本地技能列表

### Requirement: 更新中心
更新中心 SHALL 列出所有存在落后安装的技能（图标、更新说明、版本 from→to、受影响安装数、逐项"更新"），顶部工具栏在有可更新项时显示"全部更新 (N)"；全部最新时显示空态。更新执行前 MUST 自动备份。

#### Scenario: 全部更新
- **WHEN** 用户点击"全部更新 (2)"
- **THEN** 两个技能的全部落后安装升至最新，徽标消失并显示空态

### Requirement: 设置
设置 SHALL 含两个 tab：技能来源（中心存储位置切换 内置/共享、分发方式切换 symlink/复制、GitHub 仓库列表与添加表单[Owner/仓库名/分支/子目录]、内置仓库不可删、ZIP 导入、Deep Link 示例复制）与备份管理（保留策略说明、备份列表：技能/版本/原因/大小/时间/恢复/删除，空态说明）。

#### Scenario: 添加自定义仓库
- **WHEN** 用户填入 owner 与仓库名点击添加
- **THEN** 仓库出现在列表且其技能可在本地模式安装；未填必填项时提示"Owner 和仓库名必填"

### Requirement: 登录与服务配置
登录弹窗 SHALL 支持配置服务地址并登录/保存；登录后显示当前身份并提供退出登录（退出进入本地模式）。桌面登录 MUST 使用与 CLI 相同的设备码流程或直接凭据流程之一，token 安全存储于系统用户目录。

#### Scenario: 退出登录进入本地模式
- **WHEN** 已登录用户点击"退出登录"
- **THEN** 连接卡变为"本地模式 · 未登录"，市场与更新中心转为门控页，本地技能管理不受影响

### Requirement: Deep Link 安装
客户端 MUST 注册 `ripple://` 协议：处理 `ripple://install?skill=<slug>[&version=<v>]`——唤起（或聚焦）应用并直接进入该技能的安装（同步弹窗）流程；未登录且来源为 Ripple 服务时先引导登录。

#### Scenario: 网页点击安装唤起客户端
- **WHEN** 已安装客户端的用户在 Web 详情页点击"安装"
- **THEN** 桌面客户端被唤起并弹出该技能的目标选择弹窗

### Requirement: 状态栏与扫描
主界面底部 SHALL 常驻状态栏：已检测 Agent 数、项目数、本地技能数与上次扫描时间；"重新扫描"触发 hub 扫描并以 toast 汇报结果。

#### Scenario: 手动重新扫描
- **WHEN** 用户点击"重新扫描本地目录"
- **THEN** 扫描完成后状态栏计数刷新并提示扫描结果

### Requirement: 应用自动更新
客户端 SHALL 通过 GitHub Release 检查并下载自身更新（electron-updater），下载完成后提示重启应用生效；检查失败不阻塞使用。

#### Scenario: 有新版本
- **WHEN** GitHub Release 存在更高版本
- **THEN** 客户端后台下载并提示"重启以更新"
