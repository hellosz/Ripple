# desktop-client（delta）

## ADDED Requirements

### Requirement: 社区开源一级视图
主导航技能市场之下 MUST 新增「社区开源」：按来源仓库分组列出技能（名称/版本/描述/安装态/更新态/更新时间），支持安装与查看；未绑定来源时给出引导。

#### Scenario: 浏览并安装社区技能
- **WHEN** 用户进入社区开源并安装某技能
- **THEN** 技能进入本地列表且 origin 为该仓库

### Requirement: 更新中心合并与本地标记
更新中心 MUST 同时展示技能市场更新与社区开源更新（分节）；对应本地技能行 MUST 显示"有更新"标记及来源徽标。

#### Scenario: 社区更新可见
- **WHEN** 某来源仓库技能指纹变化
- **THEN** 更新中心社区节出现该技能，本地行出现更新标记
