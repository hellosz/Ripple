## ADDED Requirements

### Requirement: 导航容器具备横向呼吸空间
系统 SHALL 让顶部导航的内部内容在桌面宽屏下与页面边缘保持足够的横向留白，避免 Logo 与操作入口贴边。

#### Scenario: 宽屏导航留白充足
- **WHEN** 在桌面宽屏（≥1280px）渲染顶部导航
- **THEN** 导航内部容器横向 padding 不小于 24px，Logo 与最右操作入口不贴近视口边缘

### Requirement: 导航容器具备清晰的层次
系统 SHALL 让顶部导航通过半透明背景与底部边框与页面内容形成可感知的容器区分。

#### Scenario: 导航背景可感知
- **WHEN** 顶部导航渲染或随页面滚动
- **THEN** 导航带半透明背景，且底部有可见边框，与下方内容有清晰的边界
